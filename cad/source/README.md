# Editable CAD source

[`ov9281-camera-module.FCStd`](ov9281-camera-module.FCStd) is the editable native model.

## Model information

- Authoring application: FreeCAD 1.1
- Units: millimetres
- Coordinate system: PCB center XY=(0,0), PCB rear surface Z=0, lens direction +Z
- Structure: colored, named objects grouped by PCB, camera, connectors, rear components, hardware, and external FFC
- External dependencies: none required to open the FCStd file

The model is a physical-fit reference reconstructed from measurements and photographs. It is not the manufacturer's original electrical or production CAD. See the repository root README for print-specific simplifications.
